# My Budget

A simple expense tracker built with **React 16** to help you manage your income and expenses efficiently.

![my_budget](https://github.com/ainkhm/my_budget/blob/main/.github/cover.png?raw=true)

## Features

- Balance Overview: Displays your current balance, total income, and total expenses.
- Transaction History: View a list of past transactions with amounts and types (income or expense).
- Add Transactions: Add new transactions by specifying a description and amount (positive for income, negative for expenses).
- Dynamic Updates: Automatically updates the balance, income, and expense values after adding transactions.

### Install

Clone the repository and install dependencies:

```bash
git clone https://github.com/ainkhm/my_budget.git
cd my_budget
npm install
```

### Tech Stack

- Frontend: **React 16, CSS**
- State Management: **Context API**
- Build Tool: Create React App
